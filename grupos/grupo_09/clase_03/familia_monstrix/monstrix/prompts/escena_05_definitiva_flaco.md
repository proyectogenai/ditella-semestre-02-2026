# Escena 5 — Universidad · PROMPT DEFINITIVO FLAKO (un solo prompt, con NODI)

> **EN PAUSA — NO USAR POR AHORA.** El flujo vigente es escena general +
> agregar densidad, sin NODI ni familia. Este archivo queda como alternativa
> guardada, por si más adelante se vuelve al modo buscable.

Versión **reduced** del definitivo: mismo lugar, misma multitud, mismas seis
piezas grandes, NODI incluido, pero con la mitad de microescenas, menos
escondites y menos trampas. Sirve cuando el prompt largo le deja al modelo la
imagen demasiado cargada o cuando querés un render rápido para testear.

NO es el prompt de calidad: el definitivo largo es el bueno para la versión
final del atlas. Este es para probar, comparar o sacar un render rápido.

Se pega tal cual en el generador. Formato: 16:9 apaisado panorámico.
