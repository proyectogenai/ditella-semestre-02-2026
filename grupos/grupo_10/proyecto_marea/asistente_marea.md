# Proyecto Marea — marca del grupo

**Marca:** Marea — tintas de maquillaje para playa y pileta.

## Estado actual (agosto 2026)

La skill vigente del sistema visual es `sistema-visual-marea/` (esta
carpeta):

- `SKILL.md` — versionada acá para que todo el grupo la use y la instale
  en su agente.
- `frasco_referencia.jpeg` — imagen de referencia del envase, para subir
  en cada generación.

Para instalarla: copiar la carpeta `sistema-visual-marea/` a
`~/.config/opencode/skill/` (opencode) o `~/.claude/skills/` (Claude
Code).

## Qué es Marea

Marca ficticia de tintas de maquillaje para playa y pileta. Atmósfera:
maximalista, soleada, retro, audaz · Nunca: corporativa, de oficina, ropa
elegante o formal.
