# Respuestas

Acá vive la respuesta de la cátedra a cada duda que los alumnos dejaron en
su repaso. La estructura espeja la de `grupos/`:

```
respuestas/grupo_XX/repaso_clase_XX/nombre_apellido.md
```

Un archivo por alumno, en la misma carpeta de clase donde ese alumno dejó
su duda (`grupos/grupo_XX/repaso_clase_XX/dudas_nombre_apellido.md`). Si un
alumno repasó y no le quedó ninguna duda pendiente, igual tiene su archivo
acá con una nota breve — así queda registro de quién ya repasó, sin tener
que ir a buscarlo en el historial de git.

Cuando se agregue el repaso de una clase nueva, se suma la carpeta
`repaso_clase_XX/` correspondiente dentro de cada grupo que tenga algo que
responder — no hace falta crearla de antemano para todos.
